# Archived Starter Kit challenge drafts

These documents are preserved as historical context, **not current TikTok
TechJam 2026 submission rules or AgentLens setup instructions**. The application
and its build do not use them. They were moved here to keep the active document
index focused without discarding their provenance.

- [Three-day extension guide](HACKATHON_EXTENSION_GUIDE.md)
- [Original XML outline](hackathon-v2-skeleton.xml) and the nine numbered XML sections

In particular, the old [deliverables section](hackathon-v2-section-6.xml) says
that no product video is required, and several drafts mandate exactly one
middleware example. Do not apply those statements to the current submission.
The current track permits adapted, combined or team-designed middleware, and
the [competition portal](https://tiktoktechjam2026.devpost.com/) requires a public
three-minute YouTube demonstration along with written description and public
source. Consult the [official rules](https://tiktoktechjam2026.devpost.com/rules)
and current track statement for authoritative requirements.

Use the [reviewer runbook](../../RUNBOOK.md) to run AgentLens and the
[submission checklist](../../submission/SUBMISSION_CHECKLIST.md) to prepare its
materials. Check against the official portal before submitting; neither this
archive nor the checklist is evidence that a submission has been completed.
