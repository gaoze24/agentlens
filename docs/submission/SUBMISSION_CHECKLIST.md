## 演示准备

按 [DEMO.md](DEMO.md) 排练和录制；不在多份文档中维护不同版本的脚本。
主线是正常任务、Trace/导出、操作员取消、重新启动后继续执行。
不要把工具测试失败当作必然的 Run 失败，也不要用 fixture 冒充真实运行。
